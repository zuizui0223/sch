# SCH supported-Pareto compromise geometry v1

## Purpose

Place the shared-coordinate compromise problem inside multi-objective optimization.

The result clarifies an important limitation of functional-weight experiments: changing positive weights can only visit **supported** Pareto compromises. A biologically feasible compromise may be Pareto-efficient yet unreachable by any positive weighted-sum manipulation when the attainable loss set is nonconvex.

## Setup

Let the shared phenotype be `z` and define the vector of function-specific losses

\[
\boldsymbol\ell(z)=(\ell_1(z),\ldots,\ell_n(z))\in\mathbb R^n.
\]

For a positive functional-weight vector `w>0`, define

\[
L^*(w)=\min_z w^\top\boldsymbol\ell(z)
\]

and let `z*(w)` be a minimizer.

A loss vector `y` is Pareto dominated if another attainable vector is no larger in every component and strictly smaller in at least one component.

## Theorem 1 — every positive-weight optimum is Pareto efficient

Suppose `w_i>0` for every function. If `z*(w)` were dominated by another phenotype `z'`, then

\[
\ell_i(z')\le\ell_i(z^*)\quad\forall i
\]

with a strict inequality for at least one function. Positive weighting would imply

\[
w^\top\boldsymbol\ell(z')<w^\top\boldsymbol\ell(z^*),
\]

contradicting optimality.

Therefore

\[
\boxed{z^*(w)\text{ is Pareto efficient for every }w>0.}
\]

## Theorem 2 — the optimized conflict load is a concave homogeneous value function

For fixed phenotype `z`, the map

\[
w\mapsto w^\top\boldsymbol\ell(z)
\]

is linear. The pointwise minimum of linear functions is concave. Hence

\[
\boxed{L^*(\theta w+(1-\theta)v)\ge\theta L^*(w)+(1-\theta)L^*(v)}
\]

for `0<=theta<=1`.

Also, for every scalar `a>0`,

\[
\boxed{L^*(aw)=aL^*(w).}
\]

Thus only relative weights determine the compromise phenotype; common scaling changes the value but not the optimizer.

## Theorem 3 — the selected loss vector is a supergradient in weight space

Let `z*=z*(w)`. For any other weight vector `v`,

\[
L^*(v)
=\min_z v^\top\boldsymbol\ell(z)
\le v^\top\boldsymbol\ell(z^*)
\]

so

\[
\boxed{
L^*(v)
\le
L^*(w)+(v-w)^\top\boldsymbol\ell(z^*).
}
\]

Therefore the selected loss vector is a supergradient of the concave value function `L*`.

At a regular unique optimum where `L*` is differentiable,

\[
\boxed{\nabla_wL^*(w)=\boldsymbol\ell(z^*(w)).}
\]

This recovers the previously derived component-wise shadow-price identity in vector form.

## Theorem 4 — positive weight sweeps recover only the supported Pareto frontier

Call an attainable Pareto loss vector `y*` **supported** if there exists `w>=0`, `w!=0`, such that

\[
y^*\in\operatorname*{argmin}_{y\in\mathcal Y}w^\top y,
\]

where

\[
\mathcal Y=\{\boldsymbol\ell(z):z\text{ feasible}\}.
\]

Every compromise generated by a weighted-sum SCH experiment is supported by construction.

If the lower attainable loss set is convex and closed, supporting-hyperplane arguments recover every properly supported Pareto point with a nonnegative weight vector. But if the attainable loss image is nonconvex, Pareto-efficient points can exist above the lower convex envelope and be unsupported.

Hence

\[
\boxed{
\text{Pareto efficient}\not\Rightarrow\text{reachable by a functional-weight sweep}
}
\]

without an additional convexity/support assumption in loss space.

## Example — an unsupported compromise

Consider three attainable loss vectors

\[
A=(0,4),\qquad B=(2,3),\qquad C=(4,0).
\]

`B` is Pareto efficient: neither `A` nor `C` improves both functions.

For normalized positive weights `(w_1,w_2)`, `B` would have to satisfy simultaneously

\[
2w_1+3w_2\le4w_2
\]

and

\[
2w_1+3w_2\le4w_1.
\]

These require

\[
2w_1\le w_2,
\qquad
3w_2\le2w_1,
\]

which cannot both hold for positive weights. Thus `B` is Pareto efficient but unsupported.

## Corollary — kinks in weight space

If two distinct compromise phenotypes minimize the same weighted loss at a weight vector `w`, the value function can be nondifferentiable there. The supergradient set then contains multiple attainable loss vectors.

A kink therefore means

```text
multiple co-optimal supported compromises / a switch of the selected supported state
```

not automatically

```text
history dependence or hysteresis.
```

Dynamic hysteresis requires an additional path/history model and belongs outside this static SCH statement.

## Empirical consequences

A functional-weight experiment can now distinguish three questions:

1. **Pareto efficiency** — is a phenotype nondominated across measured functions?
2. **supportability** — can some registered positive weighting make it optimal?
3. **weight accessibility** — does the experimentally realizable weight range actually reach that supporting normal?

This matters for generality tests. Failure to observe an intermediate compromise under weight manipulation need not mean it is biologically infeasible; it may be an unsupported Pareto state.

Conversely, a smooth weight sweep that traces one continuous supported frontier is a stronger signature of the registered shared-coordinate model than isolated intermediate phenotypes.

## Claim ceiling

The theorem is static. It assumes the same feasible phenotype set and loss functions while weights change. A nonconvex loss image, multiple local optima, developmental accessibility changes, or weight-dependent loss functions can all generate richer behavior. Supported-Pareto geometry does not establish evolutionary stability, invasion, or PAYOFF dynamics.
