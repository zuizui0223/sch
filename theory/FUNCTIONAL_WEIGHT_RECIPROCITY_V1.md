# SCH functional-weight reciprocity theorem v1

## Purpose

Derive a direct cross-intervention symmetry that can falsify the regular shared-coordinate model without knowing the underlying trait Hessian or function gradients separately.

The symmetry follows because optimized conflict load is a scalar potential in functional-weight space.

## Setup

Let

\[
L^*(w)=\min_z\sum_i w_i\ell_i(z)
\]

with a unique regular shared optimum `z*(w)`. The envelope theorem gives

\[
\frac{\partial L^*}{\partial w_i}
=\ell_i(z^*).
\]

Define the optimized residual loss of function `i`:

\[
r_i(w)=\ell_i(z^*(w)).
\]

Thus

\[
r_i=\frac{\partial L^*}{\partial w_i}.
\]

## Theorem 1 — cross-weight reciprocity

Where `L*` is twice continuously differentiable, equality of mixed partial derivatives gives

\[
\boxed{
\frac{\partial r_i}{\partial w_j}
=
\frac{\partial r_j}{\partial w_i}.
}
\]

Using the d-dimensional curvature theorem, both sides equal

\[
\boxed{
-g_i^\top H^{-1}g_j.
}
\]

This is a Maxwell-type reciprocity relation for multifunctional compromise.

Interpretation:

> the effect of increasing function `j`'s weight on function `i`'s optimized residual loss must equal the reciprocal effect of increasing `i`'s weight on function `j`'s residual loss, when measured on the same additive weight scale.

## Corollary 1a — log-weight scaled reciprocity

Since

\[
\frac{\partial r_i}{\partial\log w_j}
=w_j\frac{\partial r_i}{\partial w_j},
\]

we have

\[
\boxed{
\frac{1}{w_j}
\frac{\partial r_i}{\partial\log w_j}
=
\frac{1}{w_i}
\frac{\partial r_j}{\partial\log w_i}.
}
\]

So experiments that manipulate multiplicative functional demand can still test reciprocity after the known weight scaling is removed.

## Theorem 2 — response matrix is symmetric negative semidefinite

Define

\[
M_{ij}
=
\frac{\partial r_i}{\partial w_j}.
\]

Then

\[
\boxed{
M=\nabla_w^2L^*
=-G^\top H^{-1}G
}
\]

is symmetric and negative semidefinite.

Hence for any small weight perturbation `v`,

\[
\boxed{v^TMv\le0.}
\]

The optimized residual-loss vector is therefore a conservative response field generated by the concave potential `L*(w)`.

## Corollary 2a — closed-loop integral vanishes

For any sufficiently smooth closed loop in functional-weight space that stays in the same regular model region,

\[
\boxed{
\oint \sum_i r_i(w)\,dw_i=0.
}
\]

Thus changing functional weights around a closed cycle returns the optimized conflict potential to its original value with zero net line integral.

A reproducible nonzero loop integral is evidence that at least one assumption changed around the cycle: the loss family, accessible phenotype set, state/history, or optimization branch.

## Theorem 3 — local reciprocity does not require scalar trait dimension

The symmetry holds for arbitrary shared phenotype dimension `d`. It is therefore logically distinct from the scalar rank-one signature.

A system can satisfy reciprocity while requiring `d>1`; conversely, failure of reciprocity rejects the regular potential model before asking what `d` is.

This creates a useful testing order:

```text
1. reciprocity / potential consistency
2. low-rank curvature dimension
3. specific function-gradient geometry
```

## Empirical design

With independently manipulable functional weights `w_i,w_j`, estimate the two cross responses:

\[
\partial r_i/\partial w_j
\quad\text{and}\quad
\partial r_j/\partial w_i.
\]

A preregistered equivalence test can ask whether their difference is within a biologically meaningful tolerance around zero.

For more than two functions, the full cross-response matrix should be symmetric after scale correction. This is stronger than testing each optimum shift separately.

## Claim ceiling

Reciprocity is local and assumes a unique smooth optimum, fixed loss functions under weight manipulation, and no state/history dependence. Nonsmooth optimum switching can produce kinks where ordinary derivatives fail; one-sided/subgradient analysis is then required. The theorem is a static SCH potential result, not PAYOFF dynamics.
