# Pedicularis Experiment A three-world export v1

## Purpose

Chapter 1 / SCH must deliver both pieces later chapters need from **the same population and season**:

1. state-specific shared-coordinate reference geometry;
2. a fitness-scale shared conflict budget.

Experiment A remains:

```text
z x P x independent seed-predator G
water-y held fixed
```

The full-surface analysis returns `SCH_PEDICULARIS_FULL_SURFACE_WRAPPER_V2`; the fitness-scale component analysis returns the conflict budget exported through `THREE_WORLD_CONFLICT_HANDOFF_V1`.

`PEDICULARIS_THREE_WORLD_SCH_BUNDLE_V1` validates that these outputs refer to the same population/season and bundles:

```text
context_id
fitness_scale_id
z_P*
z_G*
z_C*
L + 95% interval
independent-G / fixed-water-y guards
```

## Why both outputs are required

BALANCE needs `L` on the common fitness scale before it can classify the direct shared-versus-y-enabled worldline. BITA needs the frozen state-specific `z_P*` reference before it can calculate

```text
R_state = |x0* - z_P*| - |x1* - z_P*|.
```

If these came from different populations or seasons, the three-chapter chain would not be identified.

## Next handoff

Experiment B uses the same population, season and fitness scale:

```text
>=5 exsertion x levels x water-y disabled/enabled
```

and exports `PEDICULARIS_XY_SURFACE_HANDOFF_V1` for BALANCE and BITA.

## Claim ceiling

A positive Experiment-A bundle establishes contemporary same-context SCH reference geometry plus conflict budget only. It does not establish BALANCE occupancy, dimensional release, structural architecture cost, or historical modularization.
