## Retrieval order

The next literature expansion should prioritize missing geometry rather than more examples of generic multifunctionality.

1. `SEPARATED_OPTIMA`: same coordinate with function-specific preferred states or fitted optima.
2. `COMBINED_INTERMEDIATE_OR_COMPROMISE`: same fitness scale showing a combined optimum between function-facing states.
3. matched context shifts: the same coordinate and functions measured across environments, populations, years, or consumer regimes.
4. aligned-optimum negative controls: multifunctional traits where both functions favor the same state.
5. non-floral generality systems: one shared coordinate serving distinct functions outside pollination-antagonism.

## Minimum metadata

Every admitted cluster should preserve:

`cluster_id`, source identity, taxon/domain, shared coordinate, function 1, function 2, pattern class, context axis, design/evidence level, confidence, quantitative compatibility, source basis, and claim ceiling.

## Quantitative rule

Do not construct one cross-system grand mean. Quantitative pooling is allowed only within biologically compatible strata with a common effect definition. Directional recurrence and moderator structure are primary outputs when pooling is not defensible.

## Final experimental layer

Only after the synthesis has mapped recurrent signatures and remaining identification gaps should a focal `z x P x G` experiment be selected. Its purpose is to close the strongest unresolved causal intersection, not to serve as the entry point for SCH empirical support.
