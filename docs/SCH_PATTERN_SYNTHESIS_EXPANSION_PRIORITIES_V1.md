# SCH pattern-synthesis expansion priorities v1

## Current universe

The source-adjudicated universe currently contains 16 independent biological clusters. It is intentionally theory-targeted and heterogeneous; it is not a prevalence sample.

Current pattern classes:

- 4 `OPPOSING_DIRECTION` clusters;
- 7 `CONTEXT_WEIGHT_SHIFT` clusters;
- 2 `SHARED_TRACKING_NO_CONFLICT` negative controls;
- 1 `SHARED_TRACKING_CONFLICT_CANDIDATE` with incomplete antagonist-loss fitness attribution;
- 1 `COMBINED_INTERMEDIATE_OR_COMPROMISE` cluster;
- 1 `SEQUENTIAL_FILTER_COMBINATION` boundary cluster.

## Retrieval order

The next literature expansion should prioritize missing identification geometry rather than generic multifunctionality.

1. `SEPARATED_OPTIMA`: same coordinate with directly estimated function-specific preferred states/optima and uncertainty.
2. replicated `COMBINED_INTERMEDIATE_OR_COMPROMISE`: common-fitness evidence for a combined state/surface between component demands.
3. matched context shifts: the same coordinate and functions across environments, populations, years, or consumer regimes.
4. aligned-optimum negative controls: multifunctional traits where both functions favor the same state.
5. non-floral generality systems: one shared coordinate serving distinct functions outside pollination-antagonism.
6. design-eligible quantitative negatives: studies that satisfy the numerical design contract but do not show the preregistered conflict pattern.

## Minimum metadata

Every admitted cluster should preserve:

`cluster_id`, source identity, taxon/domain, shared coordinate, function 1, function 2, pattern class, context axis, design/evidence level, confidence, quantitative compatibility, source basis, and claim ceiling.

## Quantitative rule

Do not construct one cross-system grand mean from heterogeneous metrics. Pool only biologically compatible strata with a common effect definition and valid uncertainty. If inclusion is conditioned on the observed opposing-sign pattern, any positive-only pooled estimate is conditional on admission and cannot be interpreted as an unbiased design-wide mean or an independent recurrence test.

Directional recurrence, specificity controls, context structure, and identification gaps remain primary outputs when pooling is not defensible.

## Final experimental layer

Only after the synthesis has mapped recurrent signatures and remaining identification gaps should a focal selective `z x P x G` experiment be prioritized. Its purpose is to close the strongest unresolved causal intersection and, if justified, test promotion from state-specific reproductive optima to context-stable function-specific optima. It is not the entry point for SCH empirical support.
