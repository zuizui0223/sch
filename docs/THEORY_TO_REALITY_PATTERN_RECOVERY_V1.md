# SCH theory -> reality-pattern recovery v1

## Primary sequence

SCH is ordered as:

```text
mathematical conflict-identification mechanism
-> observable literature signatures
-> source-adjudicated metadata / compatible quantitative recovery
-> only then focal causal identification experiment
```

The empirical programme does not begin by asking one species to prove SCH. Mathematics first defines what would count as genuine shared-coordinate functional conflict; the synthesis then asks whether lower-identification signatures of that geometry recur across independent biological systems. A focal `z x P x G` experiment is retained as the final upgrade for quantities the literature cannot identify directly.

## Fixed theoretical object and identification boundary

SCH concerns one coordinate `z` serving multiple functions. At theory level, pure function-specific optima differ:

```text
z_F1* != z_F2*
```

and shared use of `z` creates a compromise load under the stated fitness model. The literature synthesis must not silently replace those pure-function optima with consumer-state reproductive optima. In particular:

```text
state-specific reproductive optimum != pure-function optimum by default
multifunctionality != identified functional conflict
```

Observable theory-linked signatures include:

```text
opposing function-mediated selection on one coordinate
separated function-specific optima when directly identified
combined/intermediate compromise geometry
context-dependent shifts in functional weighting or favored trait state
aligned-optimum / no-conflict cases as specificity controls
```

The universal object is shared-coordinate conflict geometry, not any particular pollination-defence story.

## Metadata-level observable signatures

Code one independent biological cluster for the strongest recoverable evidence on:

```text
shared_trait_coordinate
function_1
function_2
function_1_direction_or_optimum
function_2_direction_or_optimum
combined_or_realized_state
context_axis
context_change
selection_or_performance_shift
fitness_or_reproductive_consequence
study_design
source_verification_state
```

Primary pattern classes:

1. `OPPOSING_DIRECTION` — the same trait receives opposing function-linked selection or performance gradients.
2. `SEPARATED_OPTIMA` — function-specific optima are directly estimated and differ.
3. `CONTEXT_WEIGHT_SHIFT` — changing ecological context changes the effective favored value or gradient of the same coordinate.
4. `COMBINED_INTERMEDIATE_OR_COMPROMISE` — the joint state or total-fitness surface is intermediate/hump-shaped relative to component demands.
5. `SHARED_TRACKING_NO_CONFLICT` — both functions favor the same direction/state; a required negative/boundary class.
6. `SEQUENTIAL_FILTER_COMBINATION` — functions act at different fitness stages rather than as one simultaneous shared-coordinate estimand.
7. `UNRESOLVED` — the relevant architecture exists but direction/optimum separation cannot be identified.

## Synthesis targets

The primary output is not one universal pooled coefficient. Recover:

```text
recurrence of opposing-direction / separated-optimum signatures
context-dependent weighting or selection changes
combined-compromise signatures
aligned/no-conflict negative controls
study-design and estimand boundaries
compatible quantitative strata when they genuinely exist
```

Pool effect sizes only inside biologically and statistically compatible strata with valid uncertainty. Preserve biological-cluster dependence, response constructs, and function identities. Do not infer SCH loss `L`, pure-function optima, or causal compromise by averaging heterogeneous marginal effects.

## Claim ceiling

The synthesis can establish recurrence of literature-observable signatures compatible with shared-coordinate conflict and delimit where those signatures fail or change estimand. It does not by itself identify a positive SCH conflict budget `L`, prove pure-function optimum separation in any system lacking direct component identification, or prove that every coded system was generated by the SCH model.

## Final layer: focal causal identification

Only after the synthesis map is mature should a focal experiment be prioritized. A selective multi-level `z x P x G` design can recover state-specific reproductive optima, optimum shifts, and opposing component gradients. Promotion from state-specific to context-stable pure-function optima requires the separate equivalence gate defined in the current SCH manuscript architecture. The focal experiment is therefore a final identification upgrade, not the empirical entry requirement.
