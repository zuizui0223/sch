# SCH theory -> reality-pattern recovery v1

## Primary sequence

SCH is ordered as:

```text
mathematical mechanism
-> observable signatures
-> systematic metadata / meta-analytic recovery
-> only then focal causal experiment design
```

The empirical programme does not begin by asking one species to prove SCH. Mathematics first defines the shared-coordinate mechanism; the synthesis then asks whether its observable signatures recur across independent biological systems.

## Fixed theoretical object

SCH concerns one coordinate `z` serving opposing functions. The core theoretical signatures are:

```text
function-specific optima differ
shared use of z creates positive conflict loss L
combined optimum lies between / is displaced by weighted functional demands
changing relative functional demand changes the favored z state
```

The universal object is shared-coordinate conflict geometry, not any particular pollination-defence story.

## Metadata-level observable signatures

Code one independent biological cluster for the strongest recoverable evidence on:

```text
shared_trait_coordinate
function_1
function_2
function_1_direction_or_optimum
function_2_direction_or_optimum
combined_or_realized_state
context_axis
context_change
selection_or_performance_shift
fitness_or_reproductive_consequence
study_design
source_verification_state
```

Primary pattern classes:

1. `OPPOSING_DIRECTION` — the same trait is favored in opposite directions by the two functions.
2. `SEPARATED_OPTIMA` — function-specific optima are directly estimated and differ.
3. `CONTEXT_WEIGHT_SHIFT` — changing ecological context changes the favored value of the same coordinate in the predicted direction.
4. `COMBINED_INTERMEDIATE_OR_COMPROMISE` — the joint state is intermediate or otherwise lower than function-specific optima on a common scale.
5. `SHARED_TRACKING_NO_CONFLICT` — both functions track the coordinate in the same direction; useful negative/boundary evidence.
6. `UNRESOLVED` — the study contains the relevant architecture but cannot identify direction or optimum separation.

## Synthesis targets

Primary outputs are not one universal pooled coefficient. Recover:

```text
recurrence of opposing-direction / separated-optimum signatures
same-system co-occurrence of both functional routes
context-dependent reversal or displacement
trait/function classes in which conflict is absent
strength of evidence by study design
```

Pool effect sizes only inside biologically and statistically compatible strata. Preserve study/cluster dependence, response constructs, and function identities.

## Claim ceiling

The synthesis can establish that signatures predicted by shared-coordinate conflict recur in nature and identify moderators of their occurrence. It cannot infer a positive SCH conflict budget `L` from unrelated marginal studies, nor prove that every coded system was generated by the SCH model.

## Final layer: focal empirical design

Only after the synthesis map is mature should a focal experiment be prioritized. A `z x P x G` surface is the strongest causal test because it can estimate state-specific optima and a common fitness-scale conflict budget. It is a validation upgrade, not the entry requirement for the chapter's empirical half.
