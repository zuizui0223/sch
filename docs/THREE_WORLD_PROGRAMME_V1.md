# Three-world trait-architecture programme

## Chapter order

```text
Chapter 1 / SCH
shared-coordinate world
-> establish causal conflict and locate compromise

Chapter 2 / BALANCE
middle world
-> conflict is real, but differentiated architecture still does not pay
-> quantify domain position, depth, reserve, topology, and persistence

Chapter 3 / BITA
differentiated-coordinate world
-> determine when additional dimensionality wins and identify the mechanism
```

## SCH-facing interface

SCH owns the shared-world geometry. Its default empirical receipt is state-specific:

```text
z_P*, z_G*, z_C*
```

and, when the component-budget gate is satisfied, SCH can also export a fitness-scale conflict budget

```text
L > 0.
```

SCH does **not** decide by itself whether differentiation is worthwhile. That requires the counterfactual recoverability and architecture-cost information used by the next chapters.

## Handoff to BALANCE

BALANCE is defined only when the SCH-facing condition is positive:

```text
L > 0.
```

The Chapter-2 repository then combines this with the BITA-facing architecture margin

```text
Phi = sL-K
```

to study the middle world

```text
L > 0 and Phi < 0.
```

The important conceptual change is that SCH no longer jumps directly to BITA. SCH establishes the left-hand boundary and supplies the conflict geometry; BALANCE asks what ecological world exists before the right-hand architecture boundary is crossed.

## What remains SCH-specific

SCH continues to own:

- causal reconstruction of `z_P*`, `z_G*`, `z_C*`,
- optional context-stable component optima,
- opposing functional-component gradients,
- one-coordinate compromise geometry,
- evidence that multifunctionality is not automatically conflict.

BALANCE does not re-estimate those objects unless a deliberate cross-repository replication is registered.

## Claim boundary

A positive SCH conflict result establishes the left side of the middle world. It does not establish:

- that the system lies deeply inside BALANCE,
- that differentiation is close,
- that differentiation is favoured,
- that historical splitting occurred.

Those questions belong to BALANCE and BITA.
