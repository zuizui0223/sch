# SCH short-path candidate ranking v1

## Purpose

Rank biological systems for the first complete SCH mechanism experiment using causal identifiability rather than literature richness.

The target is:

```text
same manipulated A
x selective pollinator pathway P
x selective antagonist pathway G
-> one common mature reproductive W
```

A system scores highly only when the antagonist route reaches the same reproductive endpoint over a short, experimentally tractable path.

## Current shortlist

### Rank 1A — Nicotiana attenuata

Role: strongest same-coordinate reality and SCH->BITA bridge.

Recovered:

- benzylacetone is experimentally manipulable;
- BA affects pollinator-mediated reproductive success;
- BA affects hawkmoth oviposition;
- reproductive seed/capsule endpoints are tractable;
- BITA extension is unusually strong.

Penalty:

- the same hawkmoth can pollinate and oviposit;
- oviposition is not itself immediate reproductive loss;
- `G -> W` may be slow and whole-plant mediated.

Decision:

```text
KEEP AS FIRST SELECTIVITY PILOT
DO NOT GUARANTEE AS FINAL 8-CELL SYSTEM
```

Promotion requires a measurable G-mediated reduction on the declared W scale, not only egg counts.

### Rank 1B — Castilleja linariaefolia

Evidence anchor: Cariveau et al. 2004, Oikos, DOI 10.1111/j.0030-1299.2004.12641.x.

Biology:

- hummingbird pollination;
- pre-dispersal seed predation by plume moth and fly larvae;
- female reproductive success measured via seed set;
- calyx length experienced opposing selection through pollination and seed-predation pathways;
- seed predation can mask benefits of pollen supplementation.

Strengths:

- mutualist and antagonist roles are biologically distinct;
- antagonist pathway terminates directly in seeds;
- common W is naturally seed based;
- published data already show opposing selection on the same floral trait, especially calyx length;
- strong natural-world evidence that the conflict is functionally consequential rather than merely behavioural.

Current limitation:

- the key floral traits were observational rather than randomized `do(A)`;
- a clean selective seed-predator suppression intervention and a manipulable calyx/display coordinate must be recovered or newly designed.

Decision:

```text
HIGH-PRIORITY COMPLETE-SCH CANDIDATE
```

This system may be a better final SCH decomposition system than Nicotiana if a reversible/randomized A manipulation and selective seed-predator intervention are feasible.

### Rank 2 — Cucurbita pepo var. texana

Evidence anchor: Theis & Adler 2012, Ecology, DOI 10.1890/11-0825.1.

Recovered measurement architecture:

```text
fragrance A manipulated
pollination manipulated
florivores manipulated
seed production measured
```

Strengths:

- direct A/P/G/W architecture in one experiment;
- floral antagonist route is short;
- mature seed production is direct W;
- strong feasibility proof for the SCH factorial concept.

Limitation:

- enhanced fragrance increased florivore attraction but did not detect increased pollinator attraction.

Decision:

```text
BEST ARCHITECTURE TEMPLATE
NOT YET POSITIVE SAME-CUE SYSTEM FOR THE TESTED A
```

High value if another fragrance coordinate/level can be identified that changes pollinator service and florivore exposure in the same direction.

### Rank 3 — Linaria lilacina

Evidence anchor: Sánchez-Lafuente 2007, Annals of Botany.

Recovered:

- corolla structure manipulated;
- pollinator visitation and fruit set measured;
- fruit-predator suppression used after flowers ceased functioning;
- predator suppression reduced fruit predation;
- predation strongly reduced seeds per fruit;
- insecticide treatment did not detectably reduce fruit set in the published design.

Strengths:

- excellent P/G separability template;
- antagonist path is directly to developing fruit/seeds;
- common W is straightforward.

Limitation:

- tested corolla manipulations affected pollinator response but did not affect fruit-predator visitation/predation.

Decision:

```text
BEST SELECTIVITY TEMPLATE
NOT YET A POSITIVE SAME-COORDINATE SYSTEM
```

## Current interpretation

The first literature screen reveals a useful triangular pattern:

```text
Nicotiana  -> strongest same-coordinate response
Cucurbita  -> strongest full factorial architecture
Linaria    -> strongest selective antagonist suppression / short G->W
Castilleja -> strongest natural opposing selection with direct seed-predator W
```

No single recovered system yet dominates every criterion.

## Immediate ranking rule

Prioritize new source recovery in this order:

1. **Castilleja linariaefolia** — can calyx/display be manipulated experimentally, and can pre-dispersal seed predators be selectively suppressed without altering pollination?
2. **Nicotiana attenuata** — can a G contrast create measurable reproductive loss on the same W scale while preserving P selectivity?
3. **Cucurbita pepo var. texana** — is there a different scent coordinate or dose range with a positive pollinator response as well as florivore response?
4. **Linaria lilacina** — is there another floral coordinate used by both pollinators and weevil fruit predators while retaining the proven predator-suppression architecture?

## Next recovery object

The highest-value next source audit is **Castilleja linariaefolia** because it may solve the exact weakness exposed by Nicotiana: a direct seed-predator pathway with distinct mutualist and antagonist guilds while already showing opposing selection on one floral trait.

If Castilleja lacks a practical randomized A or selective G intervention, the programme returns to the Nicotiana selectivity pilot while continuing the included-study system scan.
