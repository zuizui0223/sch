# Broad multifunctional-compromise reality check v1

## Purpose

SCH is no longer restricted to pollinator-antagonist cue sharing. This audit asks whether the generalized Chapter-1 architecture — one trait serving multiple fitness-relevant functions with potentially different preferred states — occurs outside that original receiver-conflict example.

This is a **real-world grounding audit**, not a prevalence estimate and not a substitute for direct `z1*`, `z2*`, `zc*` identification.

A crucial boundary is now explicit:

```text
multifunctionality != functional conflict.
```

One trait can serve two functions whose optima are aligned. SCH requires evidence that the function-specific preferred states differ before calling the resulting phenotype a compromise.

## 1. Floral display under pollination and seed predation — positive compromise anchor

The existing SCH evidence spine contains the strongest direct ecological match to the shared-trait compromise idea. In *Dalechampia*, one showy bract-size axis increases pollination opportunity while also increasing exposure to seed predation, and the combined fitness analysis tends toward stabilizing selection.

Admitted role:

```text
SAME_TRAIT_MULTIFUNCTIONALITY
OPPOSING_FUNCTIONAL_SELECTION
CASE_LEVEL_STABILIZING_COMPROMISE
```

Claim ceiling: observational selection surface in one system; not a randomized multi-level causal optimum-shift experiment.

## 2. Floral orientation — multifunctionality without demonstrated conflict

Floral orientation provides a useful negative-control class for the generalized theory.

Yu et al. (2021; DOI `10.1111/plb.13197`) examined naturally variable orientation in *Abelia x grandiflora*. Horizontal flowers received more hawkmoth visitation and higher stigmatic pollen loads; upward-facing flowers retained more rainwater, whereas downward-facing flowers attracted fewer pollinators.

Nakata et al. (2022; DOI `10.1111/plb.13414`) experimentally altered flower angle in *Platycodon grandiflorus*. Horizontally oriented flowers received more pollinator visits and pollen transfer while also avoiding rain damage better than upward flowers.

The mapping is

```text
function 1 = pollination / pollen transfer
function 2 = abiotic rain protection
shared z   = floral orientation.
```

But the current evidence does **not** establish

```text
z1* != z2*.
```

Indeed, horizontal orientation can improve both functions simultaneously.

Admitted role:

```text
GENERAL_MULTIFUNCTIONALITY_BEYOND_ANTAGONISTS
SAME_TRAIT_BIOTIC_ABIOTIC_FUNCTIONS
NEGATIVE_CONTROL_FOR_CONFLICT
```

Primary lesson: demonstrating two functions is not enough. If both functions favor the same orientation, the system is multifunctional but not a shared-trait compromise under the SCH definition.

## 3. Flower size under reproductive benefit and drought cost — broad conflict candidate

Galen (2000; DOI `10.1086/303373`) studied flower size in the alpine wildflower *Polemonium viscosum*. Large flowers benefit reproductive performance but impose a water cost under dry conditions. Experimental watering altered the demographic consequences of floral investment, and drought changed the relationship between flower size, fecundity, and survival.

The generalized mapping is

```text
function 1 = reproductive / sexual-display performance
function 2 = water economy / viability under drought
shared z   = flower size.
```

Admitted role:

```text
BIOTIC_REPRODUCTIVE_VS_PHYSIOLOGICAL_FUNCTIONAL_CONFLICT
RESOURCE_DEPENDENT_TRAIT_COST
MULTI_LEVEL_COMPROMISE_CANDIDATE
```

Claim ceiling: the source supports a real resource-dependent conflict but does not itself recover a fully crossed `z1*`, `z2*`, `zc*` causal optimum-shift design.

This class is important because it shows that SCH can generalize beyond two receiver guilds to ecological versus physiological functions.

## 4. Floral fragrance under pollination and florivory

Theis & Adler (2012) experimentally increased floral fragrance in *Cucurbita pepo* while manipulating pollination and florivore context. Enhanced fragrance increased florivore attraction and reduced seed production without a detected increase in pollinator attraction.

Admitted role:

```text
EXPERIMENTAL_NEGATIVE_SIDE_OF_MULTIFUNCTIONAL_SURFACE
FUNCTIONAL_CONTEXT_CHANGES_NET_VALUE_OF_Z
```

Claim ceiling: does not by itself locate an interior optimum.

## 5. Context-dependent maintenance instead of one intermediate optimum

The *Primula farinosa* programme shows that opposing functional pressures can maintain alternative display states through frequency dependence and spatially varying selection rather than one continuous intermediate `z`. Longer-term manipulations link pollinator-versus-grazer regimes to changes in morph frequencies.

Admitted role:

```text
MULTIFUNCTIONAL_BALANCE_WITH_DISCRETE_STATES
FUNCTIONAL_WEIGHT_CHANGE -> EVOLUTIONARY_FREQUENCY_CHANGE
```

Claim ceiling: balance need not imply one continuous internal optimum.

## 6. Experimental evolutionary redirection

The multigeneration *Brassica rapa* experiment in the SCH evidence spine shows that adding herbivory redirects pollinator-driven evolutionary trajectories. The antagonist is not a floral receiver shown to use the same cue, but the study directly supports the broader multifunctionality prediction that changing the weight of a second function changes the selected endpoint.

Admitted role:

```text
GENERAL_FUNCTIONAL_WEIGHT_CAUSES_TRAJECTORY_SHIFT
```

Claim ceiling: broad multifunctional evolution, not strict same-cue SCH.

## Generalization result

The generalized Chapter-1 architecture is biologically defensible beyond the original pollinator-antagonist case, but the audit now separates three states that must not be collapsed:

```text
A. multifunctionality with aligned optima
   z affects both functions, but z1* ~= z2*
   -> little or no compromise penalty

B. multifunctionality with opposing optima
   z1* != z2*
   -> shared-trait compromise is possible

C. multifunctionality with context-dependent weights
   functional importance changes in space/time/environment
   -> zc* or morph frequencies can move.
```

Current real-world examples support all three biological ingredients.

The strongest remaining gap is **causal identification of the compromise geometry** in one system:

```text
z1* != z2*
+
zc* identified
+
weakening function 2 -> zc* toward z1*
+
weakening function 1 -> zc* toward z2*.
```

This is the experiment SCH should prioritize. Systems such as floral orientation where both functions are aligned are valuable negative controls, not positive compromise cases.
