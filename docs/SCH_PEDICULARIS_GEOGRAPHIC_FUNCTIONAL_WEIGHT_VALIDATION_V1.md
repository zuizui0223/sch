# SCH Pedicularis geographic functional-weight validation v1

## Decision

`Pedicularis rex` provides an independent real-world validation of a central SCH prediction:

```text
one floral coordinate can be pulled in opposite directions by two functions
+
the weight of one function can vary strongly among populations
-> the realized compromise should be context-dependent rather than species-wide fixed.
```

This is an **external multiscale functional-weight validation lane**, not the
main causal compromise experiment. The 2016 source supplies trait-linked
geographic selection; Xia, Sun & Liu (2013; doi:10.1098/rsbl.2013.0387)
independently shows finer-scale spatial variation in seed-predator pressure.
The latter is pressure-only context evidence, not local exsertion geometry.

Primary source:

```text
Sun, Armbruster & Huang (2016)
Geographic consistency and variation in conflicting selection generated by pollinators and seed predators
Annals of Botany 118:227-237
DOI 10.1093/aob/mcw097
```

## System mapping

Shared floral coordinate candidates include:

```text
z = corolla exsertion beyond the water-bearing cupular bracts
z = lower corolla-lip width
```

Functions:

```text
F1 = pollination / stigmatic pollen receipt
F2 = avoidance of pre-dispersal seed predation
```

The strongest architectural candidate is floral exsertion because the published interpretation gives clear opposing directions:

```text
pollinators -> favor greater exsertion
seed predators -> favor reduced exsertion / greater protection by bract-held water.
```

## Recovered sampling scale

The study sampled 14 populations across Sichuan and Yunnan.

Published totals include:

```text
pollination:
  299 plants
  598 flowers
  14 populations

seed production / predation:
  usually 6 capsules x 20 plants per population
  12 populations.
```

In seven populations (1, 3, 5, 8, 9, 10, 11), plants used for seed outcomes were the same plants used for floral morphology / pollination measurements, although usually different flowers were sampled.

In five populations (2, 4, 6, 7, 12), labels were lost before seed scoring. Those populations cannot support individual-level morphology -> predation linkage and must remain aggregate/population evidence.

## Positive functional-conflict recovery

The joint GLM results support:

```text
greater floral exsertion
-> more pollen on stigmas

and

greater floral exsertion
-> more seed predation.
```

The authors therefore infer opposing selection:

```text
pollination favors greater exsertion
seed predation favors reduced exsertion.
```

This is a positive L1/L2-class real-world conflict result, but not a randomized manipulation of `z`.

## Geographic functional-weight variation

The key Chapter-1 value of this system is that the antagonist weight is not constant.

Published seed-predation rates span approximately:

```text
0.8% to 27.42%
```

across sampled populations.

Initial seed set varied from approximately:

```text
31.10% to 48.53%.
```

In six of twelve populations, final seed production differed significantly from initial seed set, consistent with stronger seed-predator impact in those populations.

The best final-seed-production model also retained population x seed-predation interactions, supporting geographic heterogeneity in antagonist-mediated selection.

The published conclusion is therefore especially relevant to SCH:

```text
pollinator-mediated selection direction: comparatively consistent
seed-predator-mediated selection strength: geographically variable.
```

## Finer-scale antagonist-weight context

The geographic pattern is not the only evidence that antagonist weight is
spatially labile.

Xia, Sun & Liu (2013) compared sparse/dense P. rex patches and, in 2011,
explicitly crossed local plant density with patch size. The reported
density-by-patch-size interactions were:

```text
initial seed set   F = 44.556   df 1,2047
final seed set     F =  0.023   df 1,2345
fruit predation    F = 10.605   df 1,54
seed predation     F =106.270   df 1,2345.
```

Post-hoc contrasts show a reversal in the patch-size association with seed
predation:

```text
low density:
  small patches -> higher seed predation than large patches

high density:
  large patches -> higher seed predation than small patches.
```

Thus antagonist pressure is not only heterogeneous among distant populations;
it can reorganize across local density/patch-size contexts within the same
regional system.

The especially important contrast is:

```text
seed-predation density x size interaction  VERY STRONG
final-seed-set density x size interaction  ~ ZERO.
```

Hence strong spatial reweighting of one component process need not appear as
the same spatial pattern in integrated final reproduction.

This supports a multiscale ecological reading:

```text
shared conflict direction
+
context-labile antagonist weight
+
partial masking after component processes are integrated into final fitness.
```

It does **not** create a local H2 exsertion-geometry row because Xia et al.
did not estimate exsertion-specific pollinator and predator selection within
those density x size cells.

## SCH interpretation

Write the combined fitness surface as

```text
W_j(z) = w1_j F1(z) + w2_j F2(z) - C_j(z)
```

for population `j`.

If the pollination function is broadly similar while `w2_j` varies strongly, SCH predicts:

```text
low antagonist weight
-> combined optimum shifts toward the pollination-facing state

high antagonist weight
-> combined optimum shifts toward the antagonist-protected state.
```

Thus geographic turnover in seed-predator pressure should generate turnover in compromise strength and possibly in the position of the realized optimum.

This is a direct population-level prediction of the shared-trait framework and does not require every population to exhibit the same compromise.

## What is not identified

Do not promote this study to:

```text
causal z_P*, z_G*, z_C*
causal optimum shift
pure z_F1*, z_F2*
mechanism-resolved compromise
historical modularization.
```

Reasons include:

- floral traits were observational rather than randomized;
- pollinator and predator functions were not selectively crossed;
- individual morphology and seed-predation outcomes are not linked in all populations;
- population environment can confound mean trait / interaction strength relationships.

## High-value reanalysis if supplementary/raw data permit

### R1 — geographic weight index

For each population, estimate or recover:

```text
pollination response to exsertion
seed-predation response to exsertion
seed-predation incidence / loss.
```

### R2 — compromise-strength proxy

Construct a bounded descriptive index from the opposing standardized functional slopes, while keeping it explicitly distinct from the causal SCH compromise penalty.

### R3 — population trait prediction

Test whether mean floral exsertion is displaced toward the protected state in populations with stronger antagonist weight after accounting for altitude / population structure where possible.

This remains observational validation, not causal identification.

## Relationship to Dalechampia

The two systems complement one another.

```text
Dalechampia
-> strongest case-level stabilizing-compromise anchor
-> candidate causal multi-level experiment

Pedicularis rex
-> strongest current geographic functional-weight mosaic
-> independent evidence that the antagonist side of the conflict varies among populations.
```

Together they support a stronger general statement than either system alone:

> multifunctional conflict can be real without being geographically invariant; changing functional weights is expected to move or erase the compromise.
