## Purpose

V25 retained the first prospective H2 source candidates at title/abstract stage. V26 methods-only design classification then froze four programme classes without using coefficient signs.

This PRISMA V26 overlay now closes full-text eligibility for those four programmes before numeric outcome adjudication.

SCHPRISMA-000651  Primula alpicola

All four are primary studies with repeated ecological selection contexts and a common plant reproductive endpoint.

## Evidence lane

All four are coded:

`DIRECTIONAL_OR_NEAR_PASS`

not `STRICT_LINKED_EXPERIMENT`.

The focal floral traits are observed rather than experimentally manipulated. The experimental manipulations act on pollination access and/or herbivory context, so these studies estimate context-specific phenotypic selection rather than a causal do(trait) response surface.
