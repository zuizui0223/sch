# Chapter 1 / SCH validation logic v1

## Core claim
SCH asks whether opposing functions forced onto one shared trait coordinate create a real compromise surface, and where that compromise settles.

## Theory layer
Mathematics defines the mechanism and its identifiable consequences:

- function-specific optima differ on one shared coordinate `z`;
- forcing both functions onto the same `z` creates a positive conflict budget `L`;
- the combined optimum lies where the two functional contributions balance under current context weights.

Mathematics does not claim every biological system must show this geometry.

## Primary empirical layer — reality-pattern recovery

The first empirical test is systematic synthesis across independent systems, not one focal intervention experiment. Translate the theory into observable signatures and recover their recurrence from source-adjudicated metadata and compatible meta-analytic strata.

Primary signatures include:

```text
opposing selection/performance directions on one shared trait
separated function-specific optima
context-dependent movement of the favored shared-trait state
combined/intermediate compromise states
negative cases with shared tracking but no conflict
```

Primary outputs are recurrence, co-occurrence, context switching, moderator structure, negative/boundary cases, and quantitative pooled effects only where scales/designs are genuinely compatible.

The universal object is **shared-coordinate conflict geometry**, not a specific pollination-defence mechanism and not one grand mean effect.

See `docs/THEORY_TO_REALITY_PATTERN_RECOVERY_V1.md`.

## Final validation layer — focal causal surface

After the cross-system pattern map is mature, a focal intervention surface provides the strongest causal upgrade:

```text
z x P x G
```

where `P` changes one functional contribution and `G` changes the opposing contribution while `z` is experimentally varied.

A strong focal receipt can estimate state-specific optima `z_P*`, `z_G*`, `z_C*`, selective optimum movement, and—when supported on a common fitness scale—a positive conflict budget `L`.

This experiment is the final validation layer, not a prerequisite for SCH's empirical synthesis.

## Claim boundary

Pattern recurrence does not identify `L` by combining unrelated marginal studies and does not prove every coded system was generated by SCH. The focal causal surface can strengthen identification in one system but does not establish universality by itself.

## What SCH does not test
SCH does not ask whether a second trait dimension pays, whether differentiated architecture remains disfavored despite conflict, or why an already differentiated system works. Those belong to BALANCE and BITA.

## One-line empirical question
**Do the observable signatures of shared-coordinate conflict recur across nature, and—only after that map is established—can a focal intervention surface causally recover the same geometry on a common fitness scale?**
