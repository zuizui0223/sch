# Chapter 1 / SCH validation logic v1

## Core claim
SCH asks whether opposing functions forced onto one shared trait coordinate create a real compromise surface, and where that compromise settles.

## Theory layer
Mathematics does not claim that every biological system must show compromise. It defines the mechanism and its identifiable consequences:

- function-specific optima differ on one shared coordinate `z`;
- forcing both functions onto the same `z` creates a positive conflict budget `L`;
- the combined optimum lies where the two functional contributions balance under the current context weights.

## Causal validation layer
The decisive empirical test is an intervention surface, not a correlation:

```text
z x P x G
```

where `P` changes one functional contribution and `G` changes the opposing contribution while `z` is experimentally varied.

The strongest receipt requires:

- state-specific optima `z_P*`, `z_G*`, `z_C*`;
- selective movement of the optimum when P or G is changed;
- a positive fitness-scale conflict budget `L` when the component surfaces support it;
- the same frozen `context_id` and `fitness_scale_id` exported to later chapters.

## Generality layer
Universality is not established from one species. The comparative target is recurrence of the same **shared-coordinate conflict geometry** across systems with different biological functions.

Useful external systems can differ in pollinators, antagonists, reward, defence, morphology, or other multifunctional traits. The universal object is the geometry, not a specific pollination-defence mechanism.

## What SCH does not test
SCH does not ask whether a second trait dimension pays, whether differentiated architecture is maintained, or why an already differentiated system works. Those belong to BALANCE and BITA.

## One-line validation question
**Can experimentally changing the opposing functional demands move the optimum of the same trait coordinate in the predicted directions and generate a measurable one-axis conflict budget?**
