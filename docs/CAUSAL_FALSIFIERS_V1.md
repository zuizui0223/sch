# SCH causal falsifiers v1

SCH is not supported merely because a trait is intermediate or because two consumers correlate with it. The focal one-axis mechanism must survive the following falsifiers.

## F0 — manipulation failure

Reject the causal test if the registered `z` manipulation does not create ordered realized levels or materially moves the reserved second axis / unrelated geometry.

## F1 — intervention nonselectivity

Reject a clean two-function interpretation if the `P` or independent `G` intervention changes both functional lanes beyond preregistered tolerances or changes plant condition directly.

## F2 — no state-optimum separation

If the uncertainty on the function-facing state optima does not support meaningful separation, do not call the system a shared-coordinate conflict.

## F3 — optimum shifts do not oppose

A decisive contradiction is:

```text
removing / weakening function 1 and function 2 moves the shared optimum in the same direction
```

or neither manipulation moves the optimum beyond the registered meaningful threshold.

This would be incompatible with the registered opposed-demand mechanism for that context.

## F4 — no positive conflict budget

If the bounded fitness-scale conflict budget includes zero or is too unstable to estimate, the theory-to-fitness bridge is not empirically recovered even if some state optima differ descriptively.

## F5 — boundary / non-concave surface

If the inferred optimum lies at the manipulation boundary or the relevant surface cannot support an interior optimum, report the boundary result. Do not force a quadratic compromise interpretation.

## F6 — context instability

If population, season, outcome scale, or intervention semantics change across the cells used to infer one conflict receipt, the receipt is invalid for cross-chapter use.

## Interpretation of a failure

A failed SCH test can mean:

1. the biological system does not instantiate the proposed one-axis conflict;
2. the chosen environment has aligned or weak functional demands;
3. the manipulation does not isolate the functions;
4. the shared trait coordinate is incomplete or misdefined.

It does **not** automatically support BALANCE, BITA, or PAYOFF. Those are separate hypotheses.
