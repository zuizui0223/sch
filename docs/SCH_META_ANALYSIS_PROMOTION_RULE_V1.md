# SCH quantitative meta-analysis promotion rule v1

## Purpose

The primary empirical layer is reality-pattern recovery. Quantitative pooling is a promotion available only for compatible sub-lanes; it is not required to claim recurrence of the SCH-predicted shared-coordinate conflict signature.

## Unit of independence

The independent unit is the biological study cluster. Multiple functions, years, populations, doses, treatments, or outcomes from one underlying panel do not create additional independent clusters.

## Strict component-conflict lane

A study may enter the strict numerical conflict lane only when it contains, within the same biological system:

1. the same shared coordinate or trait;
2. at least two function-specific or agent-mediated selection components;
3. a common trait standardization and fitness scale within the study;
4. opposing component directions or separately identified component surfaces;
5. source-verified numerical estimates.

Dalechampia, Silene, Fragaria, and Gymnadenia currently satisfy the biological/design signature at different levels of numerical completeness.

## Random-effects promotion gate

Do not calculate a pooled effect merely because at least three studies exist. A quantitative stratum is promoted only when all of the following hold:

```text
independent biological clusters >= 3
same estimand family
compatible effect orientation
valid uncertainty for each effect
within-study covariance handled when an effect is a difference of component estimates
no duplicate biological panel counted twice
```

If a source reports component estimates but not their covariance, do not assume independence by default. If the exact supplementary coefficient or uncertainty is inaccessible, retain the row as a strict pattern candidate with `NUMERIC_EXTRACTION_PENDING` rather than reconstructing a value from a figure.

## What may be synthesized before pooling

Before the random-effects gate is met, report:

```text
number of independent strict conflict designs
number with exact component coefficients
number with uncertainty-bearing estimates
sign/opposition recurrence
context moderators
negative/no-conflict controls
complete-optimum identification gaps
```

This is a systematic quantitative inventory, not a pooled effect.

## Claim ceiling

A pooled standardized selection contrast, if eventually available, would quantify recurrence and magnitude of opposing component selection on shared coordinates. It would still not equal the theoretical conflict loss `L`, and it would not identify bounded function-specific optima unless nonlinear fitness surfaces are separately estimated.

## Focal experiment position

The focal `z x P x G` causal surface remains the final identification upgrade after this cross-system synthesis. It is not the entry point to the empirical chapter.
