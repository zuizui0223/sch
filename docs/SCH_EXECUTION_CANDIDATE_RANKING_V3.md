# SCH execution candidate ranking v3

## Why v3 exists

A new Pedicularis manipulation precedent changes the execution ranking.

Huang, Wang & Sun (2016; DOI `10.1111/jipb.12460`) manipulated Pedicularis corolla tube length in the field, including shortening tubes by bending and fixing them with clear sticky tape rather than removing tissue.

Combined with the existing `P. rex` shared-conflict and bract-water experiments, this means Pedicularis now has:

```text
shared conflict in the focal species
+ selective antagonist-weight manipulation in the focal species
+ non-destructive z-manipulation precedent in congeners.
```

That closes more execution components than any other current candidate.

## Rank 1 conditional — Pedicularis rex

### Positive evidence already recovered

```text
shared coordinate candidate:
    corolla exsertion above the cupulate bract

pollination-facing effect:
    greater exsertion -> greater pollen arrival

antagonist-facing effect:
    greater exsertion -> greater seed predation

antagonist -> fitness:
    seed predation -> lower final viable seed production

selective antagonist-weight manipulation:
    retained vs drained bract water
    pollinator visitation P = 0.958
    initial seed set P = 0.906
    seed predation P < 0.0001
    final seed set P < 0.0001

geographic weight variation:
    seed predation 0.80% to 27.42% across populations

z-manipulation precedent:
    congeneric corolla shortening by bending + clear tape.
```

### Remaining gates

```text
P. rex multi-level exsertion manipulation: MUST VALIDATE
pollination-weight intervention: MUST CLOSE
focal population / season conflict: MUST CONFIRM
```

### Why it is now first

Dalechampia has the best existing case-level stabilizing-compromise result, but its selective antagonist intervention remains unresolved and permanent bract manipulation risks direct carbon-function confounding.

Pedicularis instead already has a demonstrated selective antagonist-weight manipulation with near-zero detected pollinator-visitation effect and a non-destructive z-manipulation precedent in the genus.

Current status:

```text
CONDITIONAL_FIRST_CHOICE_CAUSAL_COMPROMISE_EXECUTION_SYSTEM
```

The condition is successful Stage-P0 exsertion manipulation in `P. rex`.

## Cross-chapter value

Pedicularis is also unusually valuable because the same programme contains a candidate Chapter-2 second axis:

```text
x = exsertion / display-protection geometry
y = water-retention defence state of the cupulate bract.
```

Thus a successful SCH experiment could hand directly into a BITA x-y surface without changing species.
