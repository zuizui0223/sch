The legacy 16-cluster pattern ledger has been re-expressed on non-exclusive ecological outcome axes. This removes a limitation of the original one-label pattern classification: one biological system can simultaneously show conflict and context switching, or conflict and cancellation.

Examples of the gain from non-exclusive coding:

- *Pedicularis rex* is both a conflict case and a spatial context-shift case.
- *Gymnadenia conopsea* is a conflict case, a factorial context-shift case, and the current explicit cancellation case.
- *Satyrium longicauda* carries conflict-compatible gender-specific geometry plus a combined-compromise surface.
- *Platycodon grandiflorus* and *Abelia × grandiflora* remain aligned multifunctionality controls.

This pattern motivates, but does not test, the hypothesis that consumer antagonists are associated with both opposing geometry and stronger context dependence. The seed was theory-targeted and partly assembled because conflict-relevant systems were informative. It cannot estimate prevalence, odds ratios, or moderator effects.

## Why the 117-study recode is required

The current full-text systematic evidence state contains 117 included primary-study records. The macroecology candidate builder admits all 117 without conditioning on conflict sign, evidence-lane sign, or a positive ecological result.

The next inferential denominator is therefore not the 16-cluster seed. It is the subset of the 117 records that passes a prospectively frozen **design eligibility** recode while retaining positive, aligned, null, one-sided, and unresolved outcomes.

Required sequence:

```text
117 current primary-study candidates
-> source recode of common coordinate + function pair + outcome information
-> independent biological clustering
-> context-case expansion for population/year/treatment repeats
-> freeze design eligibility without using outcome sign
-> only then classify ecological outcome axes
-> H1-H4 moderator analyses
```

## Primary hypothesis carried forward

> Ecological partners determine whether multifunctionality is realized as reinforcement, opposition, context switching, compromise, or cancellation.

The macroecology layer will test narrower registered components of this statement. It will not treat literature association as experimental causality.
