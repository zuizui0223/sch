## Result A — fixed pollinator-antagonist systems have multiple geometries

Seven fixed-role axes currently have enough source information to resolve the relation between the two functional contributions.

```text
conflict / opposition              3
alignment / reinforcement          2
one-sided or null                  2
```

The count is not a prevalence estimate. The ecological result is the existence of all three outcomes inside the same pollinator-antagonist discovery frame.

Thus:

```text
antagonist present
!=
conflict necessarily present
```

The realized geometry depends on the declared trait axis and on how each ecological route contributes to plant performance.

## Result B — one ecological system can contain opposite geometries on different traits

*Gymnadenia conopsea* remains the clearest within-system example.

- flowering phenology: pollinator and herbivore components oppose one another;
- spur length: the same two agent classes reinforce the same direction.

This establishes an axis-specific rather than system-wide interpretation of functional conflict.

## Result C — strong conflict can be hidden as weak net selection

The *Gymnadenia* phenology axis retains the first explicit cancellation case:

```text
pollinator-mediated selection > 0 in one phenological direction
herbivore-mediated selection  > 0 in the opposite direction
similar additive magnitudes
=> little/no net phenology selection
```

Weak net selection therefore cannot be interpreted as weak ecological selection without component decomposition.

## Result D — consumer roles are themselves an ecological state variable

Seven axes across four clusters do not belong in the fixed-role H1 stratum.

### Role dependent

Two axes involve visitors whose role changes with floral architecture or context.

- *Primula secundiflora*: nectar-robbing bumblebees can also pollinate, with morph-dependent reproductive effects.
- highbush blueberry cultivars: floral access geometry changes legitimate versus robbing behavior.

### Benefit-cost coupled

Five axes involve interactions in which pollination benefit and exploitation/damage are intrinsically coupled.

- *Disa similis*: the same pollen-feeding beetle chews the yellow signal-bearing petal apices and pollinates the flower in the same visit.
- *Lithophragma bolanderi*: *Greya politella* can pollinate while ovipositing, with larval seed consumption occurring later in the same brood-pollination life cycle; several floral morphology axes vary with this local interaction architecture.

These cases motivate a new macroecological distinction:

```text
fixed antagonist
vs
role-switching consumer
vs
benefit-cost-coupled consumer
```

A taxonomic or behavioral label such as herbivore, robber or seed parasite is therefore not sufficient to assign a functional sign.

## Result E — context dependence is already widespread in the staged trait-axis set

Seventeen of the 24 currently recoded axes have source-supported changes across population, treatment, cultivar, morph or consumer regime. This number is descriptive only because the staged set is enriched for informative studies.

The important point is structural: context variation occurs at several levels:

1. **agent intensity** — e.g. pollinator versus grazer balance among *Primula farinosa* populations;
2. **pollinator community** — e.g. *Gentiana lutea* colour responses across populations;
3. **trait identity** — e.g. phenology versus spur length in *Gymnadenia*;
4. **consumer functional role** — legitimate visitation versus robbing, or pollination coupled to oviposition/florivory.

## Emerging ecological statement

The current source-verified development set supports the following bounded synthesis:

> **Multifunctional geometry is not a fixed property of a species or even of a mutualist-antagonist pair. It is assembled at the level of trait axis × ecological context × consumer role.**

This is the ecological extension of the original SCH identification statement.

The final macro analysis will test how far this pattern generalizes after the systematic denominator, independence clustering and sign-independent eligibility are complete.
