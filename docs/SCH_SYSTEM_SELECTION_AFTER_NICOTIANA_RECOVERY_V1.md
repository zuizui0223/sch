# SCH system selection after Nicotiana recovery v1

## Decision

The Stage-0 recovery changes the ranking of biological systems.

*Nicotiana attenuata* remains the strongest **same-coordinate reality / SCH-to-BITA bridge system**, but it is no longer assumed to be the shortest route to the first complete SCH `A x G x P` mechanism estimate.

The reason is causal distance. Benzylacetone clearly affects pollinator-mediated reproduction and also affects hawkmoth oviposition, but oviposition by *Manduca sexta* is not automatically an immediate loss to the same focal flower reproductive endpoint. The antagonist route may require egg establishment, larval feeding and whole-plant consequences before it reaches mature seed output. This weakens the directness of `G_A(p)` on a focal-flower `W` scale.

Therefore SCH now uses a two-lane system strategy:

```text
Lane A — Nicotiana
best shared-coordinate / SCH->BITA bridge
continue only if selective P/G + short G->W linkage can be validated

Lane B — short-path floral antagonist system
prioritize systems where antagonist access can be switched directly
and the resulting loss is measured on the same flower/fruit seed endpoint
```

## Current system comparison

### 1. Nicotiana attenuata

Strengths:

- one biologically interpretable attraction coordinate: floral benzylacetone;
- direct programme-level BA effect on pollinator-mediated reproduction;
- direct programme-level BA effect on hawkmoth oviposition;
- experimental reproductive endpoints are mature seed/capsule based;
- direct bridge to BITA attraction-by-defence biology.

Weaknesses:

- *M. sexta* occupies both pollinator and ovipositing antagonist roles;
- `G` is not naturally separated from `P` by visitor identity;
- oviposition is a behavioural antagonist endpoint, not yet the common reproductive loss endpoint;
- egg/larval effects can be temporally and spatially displaced from the focal flower.

Current status:

```text
L0 shared-coordinate reality: STRONG
P/G intervention tools: FEASIBLE COMPONENTS
combined selectivity: UNRESOLVED
short G -> focal W link: UNRESOLVED / POTENTIALLY WEAK
```

Promotion rule:

*Nicotiana* remains the primary complete SCH system only if a small combined-selectivity pilot demonstrates both:

1. `P` and `G` pathways can be manipulated with acceptable contamination; and
2. the chosen `G` contrast produces a measurable loss on the declared common `W` scale over the experimental horizon.

If condition 2 fails, retain *Nicotiana* as L0/shared-coordinate + BITA bridge evidence and move the complete SCH decomposition to Lane B.

### 2. Cucurbita pepo var. texana — fragrance/florivore system

Theis & Adler 2012 directly manipulated fragrance, pollination and florivores and measured seed production. The design is therefore unusually close to SCH's target measurement architecture:

```text
A = floral fragrance enhancement
P = pollination manipulation
G = florivore manipulation
W = seed production
```

Strengths:

- `A`, `P`, `G` and `W` occur in one experiment;
- antagonist route is floral and close to reproductive structures;
- seed production is a direct common endpoint;
- consumer roles are not intrinsically fused into one organismal role in the same way as *Manduca* pollination/oviposition.

Weakness:

- enhanced fragrance increased florivore attraction but did not detect increased pollinator attraction, so this source does not itself establish positive dual-audience response to the manipulated fragrance axis.

Interpretation:

This system is an excellent **measurement-architecture template** and potential execution candidate, but a new experiment would first need an `A` level/coordinate that demonstrably affects both pollinator service and florivore exposure if the intended claim is shared-cue conflict rather than antagonist-only fragrance cost.

### 3. Linaria lilacina — corolla/fruit-predator system

The published experiment manipulates corolla structure, measures pollinator visitation and fruit/seed production, and experimentally suppresses weevil fruit predation after flowers are no longer functional.

Strengths:

- pollinator and antagonist routes are physically separable;
- the antagonist is a developing-fruit predator, so `G -> W` is short and directly measurable;
- insecticide treatment strongly reduced fruit predation without detected reduction in fruit set in the published experiment;
- fruit predation was associated with substantially lower seed production;
- mature fruit/seed endpoints are tractable.

Weakness:

- the tested corolla manipulations changed pollinator visitation and fruit set but did not change fruit-predator visitation/predation. Thus the published `A` is not a positive shared cue for both audiences.

Interpretation:

This system is a strong **selective-intervention template** for `P/G/W`, but not yet a positive same-coordinate shared-cue system. A new `A` would have to be identified that both pollinators and fruit predators use.

## Strategic conclusion

No recovered system yet closes all requirements without new work.

The system-selection problem is therefore not solved by choosing the literature study that is closest overall. It is solved by separating two requirements:

```text
Requirement I  SAME-COORDINATE REALITY
               A affects both audiences

Requirement II SHORT CAUSAL DECOMPOSITION
               P and G can be selectively manipulated
               and both reach the same W directly
```

*Nicotiana* currently dominates Requirement I.

*Cucurbita* and *Linaria* provide stronger templates for Requirement II.

This suggests the next empirical search should explicitly target systems at the **intersection**:

```text
same A affects pollinator + antagonist
AND
antagonist manipulation is direct/short
AND
common mature reproductive W is measurable
AND
P/G roles are selectively separable
```

## Immediate decision tree

```text
Step 1
Run the minimum Nicotiana combined-selectivity / G->W pilot.

PASS selectivity + PASS G->W
    -> Nicotiana remains complete SCH + BITA bridge system.

PASS selectivity + FAIL weak/slow G->W
    -> Nicotiana retained for L0 + BITA.
       Complete SCH decomposition moves to short-path system.

FAIL selectivity
    -> Nicotiana retained for L0 + BITA.
       Complete SCH decomposition moves immediately.
```

In parallel, search the existing SCH included set for candidate systems satisfying all four intersection criteria above. The search should rank biological systems, not papers, and should cluster overlapping publications before scoring.

## Candidate scoring rubric

Score each system 0/1/2 on:

1. same physical/chemical/display `A` demonstrated for both audiences;
2. manipulated `A` available;
3. selective pollinator-path intervention available;
4. selective antagonist-path intervention available;
5. antagonist route directly changes mature reproductive output;
6. same `W` measurable in all cells;
7. consumer roles not intrinsically inseparable;
8. feasible replication / generation time / husbandry;
9. direct extension to a distinct `D` for BITA.

The primary complete SCH system should maximize items 1-8. Item 9 is desirable but should not override causal identifiability.

## Current recommendation

Do **not** abandon *Nicotiana* yet, because it has uniquely strong same-coordinate evidence and a powerful BITA bridge. But do **not** let that bridge value force it to serve as the complete SCH mechanism system if `G -> W` is weak or unidentifiable.

The next high-information work is therefore two parallel tasks:

```text
A. Nicotiana minimum combined-selectivity + G->W pilot contract
B. ranked recovery of short-path systems from the 117 included studies
```

Whichever closes first becomes the confirmatory SCH execution system.
